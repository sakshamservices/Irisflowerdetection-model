# 🌸 Iris Flower Classification

A Machine Learning project that classifies Iris flowers into three species:

- Iris Setosa
- Iris Versicolor
- Iris Virginica

using flower measurements such as sepal length, sepal width, petal length, and petal width.

---

## 📌 Project Overview

The Iris dataset is one of the most famous datasets in Machine Learning. The objective of this project is to train a classification model capable of predicting the species of an Iris flower based on its measurements. The dataset contains 150 samples belonging to three different Iris species. :contentReference[oaicite:0]{index=0}

This project demonstrates the complete Machine Learning workflow:

- Data Loading
- Data Preprocessing
- Train-Test Split
- Model Training
- Prediction
- Model Evaluation

---

## 📊 Dataset Information

The dataset contains:

| Feature | Description |
|----------|-------------|
| Sepal Length | Length of sepal (cm) |
| Sepal Width | Width of sepal (cm) |
| Petal Length | Length of petal (cm) |
| Petal Width | Width of petal (cm) |

Target Classes:

1. Setosa
2. Versicolor
3. Virginica

The Iris dataset consists of 150 samples with four numerical features and three flower species. :contentReference[oaicite:1]{index=1}
